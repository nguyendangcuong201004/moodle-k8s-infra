03 — Da dam may

Ho tro da nha cung cap

Trien khai tren bat ky dam may nao voi hanh vi ung dung dong nhat. Chi phan ha tang la khac nhau.

DigitalOcean

Chinh
K8s: DOKS (Quan ly)
CSDL: PostgreSQL 16 quan ly
Luu tru: Longhorn (RWX)
Can bang tai: DO Load Balancer
Tin dung: $200 / 60 ngay
Thoi gian: ~25 phut

AWS

Da thu nghiem
K8s: EKS (Quan ly)
CSDL: RDS PostgreSQL 16
Luu tru: EFS + CSI Driver
Can bang tai: NLB / Ingress Nginx
Tin dung: $300 / 12 thang
Thoi gian: ~40 phut

Azure

Da xac nhan

CSDL: Flexible Server PG 16
Luu tru: Azure Files CSI
Can bang tai: Azure Load Balancer
Tin dung: $100 / Sinh vien
Thoi gian: ~30 phut

04 — Tu dong mo rong

Horizontal Pod Autoscaler

Tu dong mo rong dua tren muc su dung CPU va Memory. He thong cung cap 3 cau hinh quy mo san co. Thuc te da kiem thu voi cau hinh Small (1-2 pods) tren DigitalOcean va Azure.

Cau hinh Nguoi dung Pod toi thieu Pod toi da Nguong CPU Nguong Memory Tang quy mo Giam quy mo
Nho < 1.0001270%80% +2 pod / 60s-1 pod / 120s
Vua 1K - 10K1465%80% +2 pod / 60s-1 pod / 120s
Lon > 10K2860%75% +3 pod / 60s-1 pod / 600s

Tai nguyen (Nho)

CPU: 200m / Memory: 512Mi

Gioi han: 500m / 1Gi

Luu tru: 10Gi

Tai nguyen (Vua)

CPU: 500m / Memory: 1Gi

Gioi han: 1500m / 2Gi

Luu tru: 20Gi + Redis

Tai nguyen (Lon)

CPU: 1000m / Memory: 2Gi

Gioi han: 2000m / 4Gi

Luu tru: 50Gi + Redis

Chinh sach mo rong HPA

# Mo rong bat doi xung: tang nhanh, giam cham
behavior:
  scaleUp:
    stabilizationWindowSeconds: 60    # Phan hoi nhanh khi co tai
    policies:
      - type: Pods
        value: 2                       # Them toi da 2 pod moi lan
        periodSeconds: 60
  scaleDown:
    stabilizationWindowSeconds: 300   # Cho 5 phut truoc khi giam
    policies:
      - type: Pods
        value: 1                       # Chi giam 1 pod moi lan
        periodSeconds: 120
05 — Giam sat

Giam sat va quan sat

He thong giam sat day du voi Prometheus, dashboard Grafana Cloud, va chi so tuy chinh cho HPA thong minh.

Prometheus

Thu thap metrics voi luu tru 6 gio. Thu thap CPU, memory, mang, va suc khoe pod cua container. Tuy chon day len Grafana Cloud qua remote_write.

Grafana Cloud

Hai dashboard tu dong: Tong quan Moodle (CPU pod, memory, HPA, CronJob) va Tai nguyen Cluster (su dung node, dia, phan bo pod).

prometheus-adapter

Cung cap chi so tuy chinh http_requests_per_second tu byte mang container, cho phep HPA mo rong dua tren luu luong thuc te.

Cac panel dashboard

DashboardPanelTruy van PromQL
Tong quan MoodleCPU theo Podrate(container_cpu_usage_seconds_total{container="moodle"}[5m])
Memory theo Podcontainer_memory_working_set_bytes{container="moodle"}
So ban sao HPAkube_horizontalpodautoscaler_status_current_replicas
Luu luong mangrate(container_network_receive_bytes_total[5m])
Tai nguyen ClusterCPU Node1 - avg(rate(node_cpu_seconds_total{mode="idle"}[5m]))
Memory Node1 - (node_memory_MemAvailable / node_memory_MemTotal)
Pod theo Nodecount(kube_pod_info) by (node)

Sao luu

./backup.sh production latest   # Chi giu ban moi nhat

# Khoi phuc tu ban sao luu:
./restore.sh production backups/file.sql.gz

# Quy trinh:

# 3. Xoa va khoi phuc schema
# 4. Tang pod tro lai
# 5. Xac nhan qua kiem tra phien ban

// Kich ban k6 (k6-moodle.js)
export default function () {
  const home = http.get(`${BASE_URL}/`);                    // Trang chu Moodle
  check(home, { 'trang chu 200': (r) => r.status === 200 });

  const login = http.get(`${BASE_URL}/login/index.php`);    // Trang dang nhap
  check(login, { 'dang nhap 200': (r) => r.status === 200 });

  sleep(1);  // Thoi gian nghi giua cac yeu cau
}
